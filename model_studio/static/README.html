CD200 Model Studio

This application runs PyTorch DNA-profile inference on the same computer as the browser. It binds to 127.0.0.1 by default.

Workflow

  1. Select the manuscript differential, regression, or custom workflow.
  2. Pan/zoom the observed-ATAC browser. Shift-drag across its ruler to mark an ROI, then choose Run selection / view. Without an ROI, the current view is used.
  3. Select Auto, MPS, CUDA, or CPU and load the model role(s).
  4. Validate the input context, scoring core, and displayed interval.
  5. Configure deletion analysis and run inference.
  6. Inspect current predicted accessibility, observed ATAC, the deletion-effect track, and filtered motifs on one aligned genomic axis.
  7. Filter motifs by expression, single differential, consensus differential, a precomputed gene list, or one selected TF.
  8. Download raw and transformed results as JSON or CSV.

Genome browser

IGV.js, mm10 chromosome sizes, and the observed SCCApos.cd200_scc signal are served locally. IGV shows 1-based coordinates; inference receives its underlying 0-based half-open interval without a coordinate shift. Select at most 2,000 bp; the model still uses a fixed 4,096-bp context.

Manuscript preset

The promoter preset scans a 4,096-bp context with the phase-3 differential head, scores the promoter core, and renders the central 2 kb. A separate regression checkpoint supplies current predicted accessibility. Predicted accessibility, deletion effect, and motif annotations share the same displayed genomic axis.

Deletion-effect scale

The plotted value is 100 × |raw deletion effect| ÷ max(|baseline prediction|), matching analysis/plot_scan_results.py::prepare_plot_effects. Raw signed effects remain available in exports.

Motif filtering

Expression mode applies baseMean only. Single and consensus differential modes add fold-change, adjusted-p, and (for consensus) same-sign requirements. Manuscript gene-list mode uses the precomputed relaxed TF list. Every mode independently applies the adjustable deletion-effect cutoff.

Speed

Batch size 32 is the fast manuscript-parity default. Display-only scanning retains the full 4,096-bp model input but evaluates only deletion windows that can contribute to the visible 2-kb track. The genome browser reads only local Zarr chunks around its viewport and bins wide views. Use full-context scope for a complete export, or batch size 1 for the legacy one-deletion-at-a-time numerical path. Auto selects CUDA, then Apple MPS, then CPU.

Start

source scripts/bundle_env.sh
"${PYTHON_CMD[@]}" -m model_studio.server

Architecture adapters

The studio uses a stable channels-last one-hot DNA contract. Model-specific adapters reconstruct checkpoints and normalize their outputs. The bundled CD200 motif CNN is registered by default.
