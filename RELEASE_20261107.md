### Scope and Contents (v0.2.0-revision-20261107)

- **Core MoDL Framework & Local Model Studio (building on public commit 000d6ba):** Provides the DNAATACMotifCNN architecture (3,222 frozen HOCOMOCO v13 motif kernels, group normalization, and dilated residual trunks), curated motif files, genomic region BEDs, two historical mouse cSCC checkpoints (SCCApos 4,096-bp profile/count checkpoint and SCCAneg/phase-3 contrast checkpoint), CLI/Markdown workflow definitions, and the locally executed Model Studio browser interface (supporting local GPU and CPU/Apple Silicon environments).
- **Vendored Caesarion Snapshot & Dependency Pinning:** Embeds a tracked source snapshot of the Caesarion package (151 source files with a cryptographic source-hash manifest and upstream MIT license metadata, excluding upstream datasets/git history) so that launchers automatically resolve the bundled snapshot without requiring access to a private repository, alongside a pinned public gcell dependency.
- **Chromosome-Held-Out Benchmarks (Single-Stage Profile/Count Models):** Includes training and evaluation code (train_torch.losses: multinomial profile NLL and MSE on ln(1 + sum(raw_target)) with training-derived count weighting), exact chromosome split manifests, newly trained model weights, and paired 1-Mb genomic-block bootstrap (2,000 replicates, seed 1729) summary tables for single-stage MoDL (2,114-bp input, central 1,000-bp output, one predeclared fold, seed 1234), freshly trained ChromBPNet (main + bias models), released human ChromBPNet fold-0 references, and native scalar-count ExplaiNN across human GM12878 (chr1, chr3, chr6 held out), human K562 (chr1, chr3, chr6 held out), and mouse cSCC SCCApos (chr16, chr8, chr9 held out from both main and bias models; chr14 validation).
- **Locus Attribution & Human TCGA ATAC-seq Summaries:** Provides reproduction scripts and processed source tables for the mouse *Cd200* Peak 2, Peak 1, and Promoter local profile correlations (980 common bases, 20-bp mean smoothing), common 2,048-bp native unscaled accessibility contrasts (log10(1 + state-normalized sum) differences comparing observed ATAC-seq, unscaled historical MoDL, and freshly trained positive/negative ChromBPNet models), bias-free ChromBPNet DeepSHAP (100 dinucleotide-shuffled references) and standalone DeepLIFT Rescale locus tracks, and the 120-donor (7-cohort) and 404-donor (23-cohort) 1-kb TCGA human ATAC-seq window summary tables (human_atac_tumor_normal_1kb/). Full raw TCGA/ENCODE archives and exhaustive genome-wide per-base prediction arrays are not redistributed.
